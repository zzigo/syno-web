# A · apomixis: detached inheritance

A is a musical interpretation of clonal reproduction, not a biological simulation. Its invariant is a recognizable inherited motif. A daughter changes its position, scale and phenotype without crossing or merging its lineage with another mother. Different lineages may occupy the same acoustic space; this does not prohibit musical harmony, collisions, or projected line crossings.

## Static A

`A534(...)` gives a whole motif a maternal capsule. `A N24 U0.08 D1` remains the precise form; bare `A` keeps these defaults. Three compact digits retain syNo's existing N/U/D tables. No new uses of G, @ or ~ are introduced.

Each capsule has the same closed five-vertex/nine-edge triangular bipyramid. Its child is smaller (80% of maternal scale down to a legible minimum). A seeded environmental deformation stretches and twists its embedding without changing vertices, connections, lineage or parent. A filament links only a child to its own parent. Gold mothers, lavender detached bodies and lit green active edges distinguish A from ordinary branch lines. Active sound geometries remain inside the capsule; silent and unborn nodes retain the quiet point representation.

D controls dispersal distance. Above 2.5, seeds make a larger spore-like jump, then visually travel along a continuous eased flight. This is a compositional gesture, not a fluid or gravitational simulation. Rendering is deterministic from the score, seed and playback time. Camera movement does not change sound.

Inside a scoped A motif, each capsule inherits the same relative onsets and duration ratios. A common allometric factor derived from U and position scales its internal timing; the mother stays unchanged. A common spatial frequency transform retains frequency ratios, including the carrier/modulator ratio. Noise kinds remain noise kinds. Written mappings, tuning and manual p keep their existing priority. Whole-motif clock stretching currently applies to internal sound events: motifs with shared output/feedback buses retain those graphs' original clocks. This prevents effects and voices drifting apart.

## Agentic A&

`A&n1r9p[?]` owns the rest of its enclosing block. `A534&(...)` marks a narrower explicit region. Accumulate preserves existing code/events and adds audible daughters. It uses the existing model gateway; no new service is installed.

The model sends a validated daughter object, not free-form syNo punctuation. It chooses parent, transposition, level, onset and duration, with optional FM/filter/pan trajectories, `rhythm`, `rest` and `timbre`. `rhythm` contains 1–8 positive duration proportions. The host writes the repeated pulse motif, including FM syntax and contours, as one named daughter function. Its cells count as one expression rather than exhausting the layer limit before timbral births can occur. The default daughter is one sustained evolving gesture. Only every third daughter may subdivide, normally keeping pulses at least 0.4 seconds; excessively short model proposals expand within the existing loop rather than shredding the motif. `rest` is a 0–9 silence digit; 2 writes `~?2`, a 20% chance per pulse per loop. The default for generated daughters is 2. The model is explicitly asked to prioritize rhythmic variability, dormant gaps and proportional variation rather than uniform beeps.

A timbral birth can select s/t/a/q/n1/n2/n3 while retaining temporal parentage. When the model keeps the maternal timbre, the host introduces a related variant every 3–5 daughters, controlled by U. Noise shifts to another noise kind; tonal waves move to a neighboring member of the tonal family. Earlier layers are never recolored. These are explicit changes in the written score, not hidden audio randomization.

The current capsule renderer describes static A geometry. A&'s written daughter gestures still use ordinary sound trajectories: explicit mother/daughter graph metadata for model-authored code is a next step, rather than an invented visual ancestry.

## Probability silence

`s220'0.2~?2` independently omits a pulse with 20% probability. `(s220 t330)~?2` gives both voices one shared draw. `~?` defaults to 50%; `~?9` is 90%; `~` is a definite rest. Rests preserve duration and identifiers, so there is no rhythmic collapse or loss of playback position. Draws are seeded and repeatable per loop; offline rendering uses the first execution's draw. Already sounding effect tails may continue through a rest.

## Compact numeric writing

Agent-written formula values have at most one decimal place. The source inherited from the performer keeps its original precision. Daughter pulse boundaries use a 0.1-second grid and stay inside the existing loop; very short daughters use fewer pulses rather than zero-duration cells. A nonzero value below a tenth is written as 0.1 (or -0.1). Raw model responses remain verbatim for inspection.
